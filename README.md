# Storage, memory and processors — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 1 Digital devices: Storage** (book pages 38–41) and **Memory and processors** (book pages 59–63). Only these pages are covered.

Each section is explained step by step with interactive simulations, followed by the book's **activities** (where the book has them) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes; Part B uses the chapter questions on page 63).

**Part A · Storage** (pages 38–41)

1. Secondary storage — storage vs memory, non-volatile, uses, internal and external devices, devices and media, backwards compatibility → ✓ Check
2. Hard disks — platters, spindle, read/write head, 5400/7200 rpm, seek time (simulation slowed down 100×), reading and writing, head crash → ✓ Check
3. Optical, flash and tape — CD/DVD/Blu-ray capacities and lasers, R/RW/RE, flash media, magnetic tape, how each media stores 0s and 1s → ✓ Check
4. Comparing media and capacity — Table 1.4, choosing media for a job, bits, bytes and units (book 1000s and specification KiB/MiB/GiB/TiB 1024s), IBM 350 vs microSD → ✓ Check
5. Test Part A

**Part B · Memory and processors** (pages 59–63)

6. Memory and RAM — storage → memory → processor (Fig 3.1), volatile, size of RAM, virtual memory on HDD/SSD, adding RAM → Activities (Using RAM) → ✓ Check
7. ROM and RAM compared — single purpose computers, booting, ROM/PROM/EPROM/EEPROM, firmware, Table 3.1 → Activities (Using different types of ROM) → ✓ Check
8. Flash memory — type of EEPROM, no moving parts, fast and low power, SSDs, USB drives and SD cards → ✓ Check
9. Processors — CPUs and cores, processor cycle, quad-core, slower cores and heat, clock speed (Table 3.2), work per cycle, the sand race → Activities (Working at different speeds) → ✓ Check
10. Test Part B · Key terms (searchable)

Note: the book's Table 1.4 gives "up to 128 GB" for hard disks; the site shows "many TB" with a footnote.

**Progress that students can share and resume** (same system as the other lessons)

- Saved automatically in the student's browser (`localStorage`, key `sm-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`SM1Z.…`) to carry on with another device.
- Nothing is sent to a server.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#hdd` or `#check-ram`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step.
